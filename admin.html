🔄 عملیات سریع

این دکمه‌ها GitHub Actions رو اجرا می‌کنن یا سایت رو باز می‌کنن.

🔑 GitHub Token

برای ذخیره تغییرات توی GitHub، لازمه یه Personal Access Token بذاری:

  1. برو به github.com/settings/tokens/new
  2. توی Note بنویس: Ariana Admin
  3. Expiration: انتخاب کن No expiration
  4. تیک repo رو بزن (همین کافیه)
  5. پایین، Generate token رو بزن
  6. توکن ghp_... رو کپی کن و اینجا پیست کن
