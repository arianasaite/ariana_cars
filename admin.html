🖼️ مدیریت عکس‌ها

برای اضافه کردن عکس، آدرس تصویر (URL) رو وارد کن. می‌تونی از سایت‌های مثل Imgur یا PostImages استفاده کنی.

🔄 عملیات سریع

این دکمه‌ها GitHub Actions رو اجرا می‌کنن یا سایت رو بازسازی می‌کنن.

🔑 GitHub API Token

برای اینکه پنل بتونه فایل‌ها رو توی مخزنت آپدیت کنه، لازمه یه **Personal Access Token** از GitHub داشته باشی.

  1. برو به github.com/settings/tokens/new
  2. توی Note بنویس: Ariana Admin
  3. توی Expiration: No expiration (یا هر چی می‌خوای)
  4. تیک repo رو بزن (فقط همینه کافیه)
  5. پایین صفحه، Generate token رو بزن
  6. توکن که به شکل ghp_... هست رو کپی کن و اینجا بذار
