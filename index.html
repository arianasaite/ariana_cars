🚀 راهنمای انتشار روی GitHub Pages

  1. ساخت حساب GitHub: اگه نداری، توی github.com ثبت‌نام کن.
  2. ساخت مخزن جدید (Repository): روی دکمه + بزن و New repository رو انتخاب کن. اسم مخزن رو مثلاً ariana-cars بذار و تیک Public رو بزن.
  3. آپلود فایل: فایل index.html رو بساز (همین کد) و توی مخزن آپلود کن. میتونی از دکمه Add file → Upload files استفاده کنی.
  4. فعال‌سازی GitHub Pages: برو به Settings مخزن → از منوی چپ Pages رو انتخاب کن. حتماً فایل رو index.html نام‌گذاری کن تا به عنوان صفحه اصلی شناخته بشه.[reference:0]
  5. تنظیمات انتشار: زیر Build and deployment → Source، گزینه Deploy from a branch رو انتخاب کن. Branch رو روی main و folder رو روی / (root) بذار و Save کن.[reference:1]
  6. انتظار و دریافت لینک: حدود ۱ دقیقه صبر کن و صفحه رو رفرش کن. سایتت روی آدرس https://username.github.io/ariana-cars/ در دسترس خواهد بود.[reference:2]
